# TypeScript fundamentals

## Purpose
Use TypeScript to make domain code safer.

## Concept and application
`strict` and `noUncheckedIndexedAccess` are inherited by the API. Interfaces such as `HealthStatus` make responses explicit; `Promise<void>` documents lifecycle work.

## Why it matters and trade-offs
Stricter checks add early friction but catch missing cases before financial data is written.
