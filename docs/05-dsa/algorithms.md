# Algorithms

## Purpose
Choose algorithms only where they improve the product.

## Concept and application
Sorting supports reports, searching supports filters, and a recurrence generates fuel coverage periods. The database should sort and filter persisted data.

## Why it matters and trade-offs
Learning code belongs in tests or an educational package, not in place of PostgreSQL primitives.

## Questions and exercise
Write a pure function that generates eight coverage periods from a 3:1 policy.
